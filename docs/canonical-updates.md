# Correct or add career information

Ask, “Correct my employment dates,” “Add this achievement,” or “I earned a new credential.” The assistant prepares the change and shows what it would affect. You review and approve it before it is saved.

Check the actual source: your statement, a work record, an original project or an issuer's award. Adding a course topic does not prove a skill. A project does not become employment, and exam preparation does not become a certification.

After a saved change, affected job comparisons, resumes and other documents may need refreshing. Earlier application records keep the exact materials you used. This helps you correct your profile without silently rewriting application history.

If two sources disagree, review the conflict rather than choosing a convenient value. A recovery message means the assistant should inspect the saved transaction and use the package's recovery process, not patch your records directly.

## Command reference

The tool sequence is `update propose`, `update preview`, user approval, `update approve` and `update commit`. `history` shows the saved record history. Exact data contracts and transaction behavior remain in the developer references and executable tests. See [privacy and review](privacy-and-approvals.md).
