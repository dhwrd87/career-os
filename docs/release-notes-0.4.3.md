# Career OS v0.4.3 — Complete Application Journey

Published release from the approved [PR #3](https://github.com/dhwrd87/career-os/pull/3). Completes the connected professional-history, master, selected-family base, live discovery, job-specific resume, application-package, tracking and development journey. See [the complete guide](complete-application-journey.md) for actual behavior and boundaries.

Packages contain self-contained Start Here pages, source/freshness and verified application links, original descriptions, qualification/employer-needs records, validated PDF/DOCX resumes, conditional PDF/DOCX letters, captured versus anticipated questions, source-bound answer drafts, unanswered details, checklists and document manifests. Answer-bank changes require approval; work permission, pay, availability and legal declarations are never guessed.

Existing engines and numeric quality gates remain. No external application submissions or commitments are implemented. Published v0.4.2/v0.4.1 and the private Career OS remain unchanged. Source coverage, form-access/conditional-question, course freshness, thin-evidence, DOCX/ATS-vendor, unverified Windows/Word/other-host and accessibility limits remain disclosed. No hiring or competitive-superiority claims.

The full journey is now the main public presentation: build your master, explore matching career paths, create career-specific resumes, find current openings, tailor individual resumes, prepare complete applications, track activity and interviews, and plan development toward better-fit roles.

Validation includes 326 tests and eight installed personas per supported Python version in CI; three representative profiles with four complete packages; actual live retrieval and question capture; PDF/DOCX review; and an exact-wheel clean installation. The [fictional application example](../examples/application-journey/README.md) includes Start Here and all local document links. It is not a live vacancy or submission portal.

The tested distribution files are unchanged from the approved candidate. The tag checkout updates release-facing documentation only; `publication-manifest.json` records those differences from the frozen source ZIP. Use the [installation guide](installation.md) and matching skill ZIP. Checksums accompany the downloads.
