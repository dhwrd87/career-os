# Layout and experience parity

This assessment is separate from functional coverage. The reference is a personal Markdown workspace and two ReportLab resume templates. Reference renderings in the gallery use the **actual reference renderers with fictional data**; no private candidate artifacts or goldens are distributed. The public candidate is generated through its executable workflows. This is layout comparison, not evidence that both engines selected identical content.

| Surface | Reference | Public candidate and rendered evidence | Assessment |
|---|---|---|---|
