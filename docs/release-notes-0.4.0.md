# Career OS 0.4.0

Career OS now exposes a complete local workflow from reviewed career evidence to job qualification, application materials, interview preparation and observed-outcome learning. It preserves the recovered source-first onboarding, canonical updates, lane inheritance, employer-needs analysis, premium presentation and conversion safeguards.

New user-facing commands generate a linked workspace home, editable DOCX resumes, evidence-linked cover letters, application tracking, local follow-up drafts, readable interview packs, career progress and learning reports. Read-only Greenhouse and reviewed-catalog discovery reconcile known opportunities before ingestion and qualification. Opportunity priorities distinguish observed evidence fit from optional user-assumed value scenarios.

This candidate repairs fragmented-source summary prose, repeated outcomes, resume-build identity and repeat preparation. PDF object preflight and geometry comparison extend the existing ATS and visual checks. MIT licensing was selected by the owner. The source, wheel and skill are packaged without private Git history or candidate dependencies.

Requirements: Python 3.11/3.12; resume extras and Poppler for the PDF path; docx extra for editable export. Local release evidence is on macOS/Python 3.12. Other OS/AI-host claims are limited to observed validation; CI configuration is not a passing hosted CI run.

Limitations: one bounded Greenhouse public-board adapter plus reviewed catalogs; other providers and scheduled alerts unverified; no external submission/sending/scheduling; one production single-column template; core Helvetica/Latin-script support rather than arbitrary branding/fonts; editable DOCX can paginate differently; semantic accessibility without PDF/UA certification; no prediction of hiring outcomes or broad labor-market coverage from a small personal cohort.

Upgrade: workspace format 1.1.0 and schema bundle 1.23.0 remain compatible. Install the matching package and skill, run doctor and verify, and review regenerated derivatives. Existing submitted artifacts remain immutable. See [publication instructions](publication.md) and the fingerprint-bound release manifest before publishing.
