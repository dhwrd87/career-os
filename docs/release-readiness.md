## Exact limitations

1. Job discovery has a bounded Greenhouse public-board reader and reviewed catalogs. Learning discovery reads public HTTPS indexes/course pages and actual metadata. Authenticated Coursera/LinkedIn Learning/Udemy search, scheduled alerts, enrollment and purchases are not implemented. Current retrieval does not prove current curriculum. Unknown level, price, currency, time or prerequisites require source review; strict constraints fail closed.
2. Learning ROI is a descriptive heuristic and the minimal path uses greedy course reuse, not a globally optimal schedule or hiring/salary prediction. Observed job samples are not the whole market. Project hours are estimates and extra project-material costs require verification. Course completion never becomes professional experience or automatically awards a credential.
3. One premium single-column PDF template is supported. Identity/career data are configurable; arbitrary fonts/themes, the private compact template and broad non-Latin-script typography are not supported.
4. DOCX is editable semantic output; LibreOffice presentation evidence is retained for the unchanged exporter. Microsoft Word pagination and every ATS vendor remain unverified. Selectable PDFs are untagged and not PDF/UA certified; core Helvetica is not required to be embedded.
5. macOS/Python 3.12 local execution is verified. Python 3.11/Linux CI is configured but hosted CI has not run. Windows and other AI-host integrations remain unobserved. The CLI and skill router are tested; universal assistant compatibility is not claimed.
6. External application submission, messaging, public-profile editing, interview scheduling and compensation commitments are not implemented. Preparation artifacts remain subject to human review.
7. The included learning example has a fixed synthetic assessment date and correctly warns when its source facts expire. Its fictional resources/prices are demonstrations, not current offers. Owner review remains the publication boundary.
