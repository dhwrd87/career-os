# A complete fictional application journey

Included in [Career OS v0.4.3 — Complete Application Journey](https://github.com/dhwrd87/career-os/releases/tag/v0.4.3).

Priya Calder and every employer, posting, question and career fact in this example are fictional. No application was submitted. The source uses example.org as a demonstration domain, not a job or application portal. The direct application link is deliberately **not verified**, and Start Here says so. Real-source retrieval and a working observed application form were verified separately; no live employer's full posting is republished here.

Open [Start Here](application/Start%20Here.html), or [its Markdown version](application/Start%20Here.md) on GitHub. Download the folder to use the HTML page locally. All application document links work within that folder.

The package contains the original fictional description, qualification and employer-needs assessments, tailored resume PDF/DOCX, required cover letter PDF/DOCX, actual fictional screening questions and supported draft answers, unanswered salary/work-permission questions, checklist, validation and the document manifest. Internal assessments are for your own review; upload only requested recruiter-facing files. No missing personal declaration is guessed.

The approved history remains in [Career Record.json](Career%20Record.json). Compare the [master resume](Master%20Resume.pdf), [implementation base](Career%20Direction%201.pdf), [training base](Career%20Direction%202.pdf) and [job-specific resume](application/Resume.pdf). These are derivatives of the same approved history. [Evidence review](Evidence%20Review.json) identifies useful missing detail; the [job-search plan](Job%20Search%20Plan.md) explains next steps.

Reproduce three representative profiles and four packages with `python scripts/build_application_example.py --output /tmp/career-journey-example` from a source checkout with the resume and DOCX extras installed. The executable path uses approved setup, direction selection, qualification, real rendering, batch packages, interview materials, fictional reported tracking events and stretch/dream plans. It never sends or submits anything.

[Read the workflow guide](../../docs/complete-application-journey.md). Source evidence still sets the writing ceiling. Letters are drafts and may be short. Form access, conditional questions, current source facts, ATS vendors, editors and supported-environment limitations remain disclosed.
