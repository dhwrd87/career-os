# Security and privacy

Career OS stores sensitive career data locally in a separately selected workspace. Generated dashboard pages and reports also contain that data. Treat the workspace and exported archives as private; do not publish them or serve them on a public web server.

Use a minimal synthetic reproduction for public issues. For a vulnerability, use GitHub private vulnerability reporting on the eventual public repository if enabled. Until a private channel is configured, do not disclose secrets or personal records in an issue; report only that private contact is needed.

The package contains no submission, messaging, payment or public-profile write adapter. Optional source enrichment performs read-only fetches only after a user decision. Review imported sources and fact proposals before committing. Protect backups and exported workspaces with the same access controls as originals.

Only the reviewed release candidate is in scope for release preparation. Dependencies have declared ranges; this candidate has no automated advisory-service audit result. CI is provided but a local run does not establish a GitHub-hosted CI result.
